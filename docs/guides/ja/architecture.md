## ソースの構成

牌とメキシカントレインの規則は、DOM や依存パッケージのない純粋な関数です。ゲームは値で、一手ごとに新しい値を返します。同じシードで同じ配りを再現します。コンピューターと保存形式は同じ規則を使う別のモジュールです。

`mexicanTrain/` に牌、設定、規則、型、コンピューター、コーデックがあります。`cli.ts` は純粋な CLI、`random.ts` はシード付き乱数、`strings.ts` と `words.ts` は案内です。録音は `sounds.ts`、読込と操作は `tile-sounds.ts` にあります。デモは状態を描き、操作をルールへ渡します。

## スナップショットではなく記録

履歴は連結した記録なので、一手追加しても以前の多数の手をコピーしません。`movesOf` は時系列、`moveCount` は記録数を読みます。保存形式は設定と手を保持し、再生で同じ規則から手牌と道を復元します。外部から渡された盤面を、そのまま合法な状態と扱う必要はありません。

主入口は DOM に依存しません。音の操作と録音は任意の別入口です。ドキュメントは公開コメントと対訳ガイドから作り、検索は静的なローカル索引です。`pnpm sounds` の生成器にも検証済みの例を保持します。
