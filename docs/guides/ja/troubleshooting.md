## ゲーム関数が null になった

`startTrain` は対応するセットと 2〜8 人を受け付け、それ以外は `null` です。現在できない手には `playTrain` が `null` を返します。`trainMoves` を確認し、未処理ダブルがすべての道を制約することに注意してください。`replayTrain` は設定や記録中の手が拒否されると `null` です。`decodeTrain` は不正な文字列や保存形式のバージョンも拒否します。シード、追加ルール、手の順序を組で保持します。

## 名前と空の一覧

未知のセットに `trainSetName` と `trainSetLabel` は `null` です。最初の手の前に案内が空なのは正常です。終了後は `trainMoves` が空になり、それ以上コンピューターの手を求めません。ラウンド終了後は `next` で次を配ります。席と道は 0 から数え、共用の道は全席の後です。

## 音と CLI

ミュート中、音声がない環境、ブラウザーが許可する操作の前には音が出ないことがあります。ホストのボタンで有効にし、撤去時に閉じます。CLI は拒否された記録に 1、使い方の誤りに 2 を返すので、`out` と `err` を確認します。指定のない置換値は波括弧のままです。

パッケージは規則とデモを提供します。ネットワークサービスや設置用の標準盤面はありません。サーバーでは他の手牌と山を公開しないようにします。[保存](saved-games.md)、[CLI](cli.md)、[音](sounds.md)を参照してください。
